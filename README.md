# 보글사다리 AUTO-RANGE80 V1.9

AUTO-RANGE80 단독 메인엔진 앱 소스입니다.

## 핵심
- 최고 삼치기 1픽 한 세트만 표시
- 학습길이 `12회 ~ 현재 확보 전체 구간` 자동 탐색
- 80% 후보 우선
- 전반/후반 안정성 검사
- PASS 없이 매 회차 최고 1픽 출력
- 자동조회 / 자동채점 / 백업 / 복원 / 리셋 포함

## Codespaces 실행
```bash
bash 보글사다리_AUTO_RANGE80_V1.9_원클릭.sh
```
